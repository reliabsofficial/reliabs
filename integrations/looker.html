Reliabs + Looker

Looker holds the business metrics that should drive product bets — but most PMs never see them before quarterly planning. Reliabs reads your Looker dashboards and surfaces the most relevant business metrics as real-time product signals in your roadmap.

What This Integration Does

The Reliabs + Looker integration connects to your Looker instance and reads the Looks and dashboards you select. Key metrics are monitored for significant changes and surfaced in Reliabs as product signals — with the business context your roadmap decisions need.

Setup

How to Connect Looker to Reliabs

1

Connect Your Looker Instance

In Reliabs Settings, go to Integrations then Looker. Enter your Looker API credentials. Reliabs uses Looker's API to read Look results and dashboard data — read-only access only.

2

Select Dashboards to Monitor

Choose which Looker dashboards and Looks Reliabs should track. You can pin your most strategically important metrics as permanent roadmap signals.

3

Set Metric Alert Thresholds

Define what constitutes a significant change for each metric — e.g., revenue drops more than 5% week-over-week. Reliabs alerts you when thresholds are breached.

4

Link Metrics to Roadmap Bets

From any roadmap bet, attach the Looker metrics that will measure its success. Reliabs monitors those metrics post-launch to track the outcome automatically.

FAQs

Reliabs + Looker — Common Questions

Does Reliabs require Looker admin access?
+

No. Reliabs uses Looker's API with the minimum permissions needed to read Look results and dashboard data. A Looker API user with Viewer access is sufficient for most integration features.

Can Reliabs run Looker queries?
+

Reliabs reads the results of existing Looks — it does not run arbitrary queries against your Looker data models. This ensures your Looker performance is not impacted by the integration.

Which Looker versions does Reliabs support?
+

Reliabs supports Looker 6.0 and above, including Looker-hosted and customer-hosted instances. Looker Studio and Google Looker Studio are separate products and have different integration support.
